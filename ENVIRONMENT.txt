왹쿡 팀 개발 환경
======================
새 패키지를 추가하거나 버전을 바꾸면 이 파일과 requirements.txt를 같이 고쳐서 PR로 올려 주세요.

[Python]
- 버전: 3.12 (.python-version과 같음)
- 가상환경: Conda
    conda create -n oekcook python=3.12 pip
    conda activate oekcook
    python -m pip install -r requirements.txt

[실행]
- 서버: python app.py → http://localhost:5000
- Docker를 쓸 때: docker compose up --build → http://localhost:5001
- 테스트: python -m unittest discover -s tests -v

[환경 변수 (.env, 커밋 금지)]
- 프로젝트 맨 위에 .env 파일을 만들고 아래 세 줄을 적는다 (.env.example은 쓰지 않음)
    OPENAI_API_KEY=운영진이 준 키
    OPENAI_MODEL=gpt-6-luna
    OPENAI_REASONING_EFFORT=none
- 추론 강도는 none으로 시작하고, 기능 테스트하면서 필요할 때만 low로
- 키가 없어도 게임은 끝까지 돌아간다(외계인 판단은 규칙, 레코드 대사는 record_lines.md 예시)
- 선택(배포에서 호출량 제한, 안 적으면 기본값)
    LLM_PER_IP_PER_10MIN=40      IP별 10분 외계인 판단 호출 수
    RECORD_PER_IP_PER_10MIN=5    IP별 10분 레코드 대사 호출 수
    LLM_DAILY_LIMIT=1500         서버 전체 하루(UTC) 호출 수
    GAME_LOG=1                   타일마다 판정·확신을 서버 로그에 남김(측정용)

[설치된 패키지] requirements.txt 기준
- Flask, python-dotenv, gunicorn, openai
